# 成图检查

只检查实际图片。提示词或方案正确不等于成图通过。每项标“通过 / 需改 / 无法判断”，附位置；未要求项可写“不适用”，不用总分掩盖失败项。

| 项目 | 检查 |
|---|---|
| 任务一致 | 画面范围、用途、品类、包装状态、保持项 |
| 分区 | 同类集中，色组辅助类目，不打散品类 |
| 商品身份 | 轮廓、颜色、配件、包装与用户素材一致；小字未知不称已核对 |
| 相对尺寸 | 用有依据的商品尺寸比较相近景深下的尺度；盘高32cm与杯高18cm不应接近等高。未知架宽不据此认证容量 |
| 支撑 | 层板接触、挂点清楚，无穿板、悬浮、融合 |
| 架体 | 层板、立柱、背板、标签轨连续；接缝/层距变化可解释 |
| 密度 | 符合用途/品类，重复有区别，无糊块、多余泵头/柄/帽尖 |
| 标识 | 关键文字逐字核查；价格/编码有来源；标签靠近对应单元 |
| 空间 | 架体、地砖、顶灯透视一致；反射不干扰商品与路径 |
| 画面 | 无无关遮挡或临时杂物；单幅任务无拼接边框 |

完整墙：
- 左右、顶底完整，主体确为一面指定墙，不是篮子/局部商品特写。
- 陈列区清晰，无浅景深或前景物隐藏要求。
- 要求的模块、层/挂杆行与分区可查，看不清标无法判断。

大景：
- 周墙、岛架、端头和主要可见通道能读懂。
- 近中远比例连续，无通道突然堵塞、架体消失或无故转折。
- 不靠无限复制表达规模；不要求远景小字可读。
- 未给定的建筑元素只能为已说明的概念设定。

成套：
- W01跨图保持模块、分区顺序、商品/包装、色组、标识。
- 墙面朝向、相邻区域一致；地面顶棚、架体与灯具统一。
- 同为蓝白色不足以判同店；遮住的部分标无法判断，必要时换视角。

局部编辑对目标区和非目标区分别核对：目标商品、架体/镜头、顶棚/地面、邻架商品/文字、亮度/锐度。主要结构保留但邻区细节重绘，只能标部分保持，不能判严格局部编辑通过。

最终结论分别列：①概念视觉；②陈列与空间；③商品外形/尺寸/包装；④按关系适用的跨图一致性；⑤局部编辑范围。允许“概念基本可用，保真/成套未通过”。真实尺寸、承重等未有实际资料时不作工程可用结论。文件与配置校验另列，不计成图通过。

优先修范围、商品身份、缺分区、支撑/透视断裂、关键文字；再调密度、材质与氛围。
记录“问题位置 → 改什么 → 保持什么 → 实际复核”，保留上一版。相同问题两轮修订无改善，呈现限制与版本，再考虑缩小画面、减少精确元素或换参考，不无界重试。

持续项目保存需求简表、参考ID/角色、提示词、图像版本、检查与用户反馈；一次性任务可在回复说明，不机械造空文件。
