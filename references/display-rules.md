# 陈列规则与依据

以下为可见关系提炼的视觉制作规则，本次用户明确要求优先。图片不证明实际尺寸、承重、库存或经营效果。

| 规则 | 执行方法 | 依据与边界 |
|---|---|---|
| 先分类再配色 | 按用途/形态成区，区内按系列、尺寸、颜色形成块面；横纵或局部块面均可 | ST017/027/030、SH006/014/027；不规定彩虹渐变 |
| 支撑与形态匹配 | 挂卡有挂点；瓶盒有层板；软物可叠；长柄物留足竖向空间 | ST025/028、SH009/036；杆长与承重未知 |
| 层距按商品调整 | 分架段定义层板/挂杆行，允许不同层距，接缝和立柱清楚 | ST008/027/030、SH014/036；不写死全店五层 |
| 主展示面朝向观看方向 | 同组前沿有秩序，保留每件独立轮廓 | SH009/016/018、ST030；器皿不强迫变扁平包装 |
| 重复形成秩序 | 门店增加合理重复面、后排或堆叠，保留不同款式与软物差异 | ST027/028/030；不把所有商品复制成完全相同纹理 |
| 密度分项控制 | 前排覆盖、重复面/后排、组间/层间留白分别描述 | ST027对比ST028；饱满不等于堵满，不编造覆盖百分比 |
| 标签跟展示单元 | 价签在层板前沿，挂陈牌跟挂位；展厅可用样品编号 | SH009/034、ST030；黄色牌不自动等于价格 |
| 大景先定义关系 | 周墙、岛架、端头、主要路径明确，前中后景各有作用 | ST017/019、SH004/006、ASH007；不无限复制架体 |
| 环境单独设定 | 顶棚、灯具、地面、架体、墙面与标识成套管理 | ST008对比ST017、SH006；黑顶、红柱、蓝带并非强制 |
| 成套共享对象身份 | 固定W01墙的模块、左右分区、商品、朝向与相邻区域 | 工作流建议，缺少可验证平面图，需实际出图检查 |

## 用途与密度

| 控制项 | 门店零售 | 样品展厅 |
|---|---|---|
| 包装状态 | 按售卖状态保留包装，拆包装由任务指定 | 可以单件样品或实物与盒装成对 |
| 数量表达 | 重复铺面、后排、堆叠，同类成组 | 款式差异优先，密度仍按品类变化 |
| 留白 | 保留轮廓和取放关系，不用糊块填空 | 可突出单品，不意味着所有架子稀疏 |
| 标签 | 已知价格或无数字中性价签 | 样品编号、条码和价格分清 |
| 不可推断 | 画面不证明实时库存或销量 | 单件展示不证明缺货 |

## 镜头与风格

完整墙：正面或轻侧视，顶底和左右边界完整，主要陈列区清晰；避免前景篮子、桌子遮挡及浅景深隐藏结构。

大景：适度斜视或纵深，周墙/岛架/端头/通道可读，架体、地砖和顶灯透视统一；远处标签自然缩小，不强求小字全部可读。空间大小不靠超广角拉伸表达。

可选预设：
- 黑框木板季节零售：AST001–006/021/028/029。橙黑万圣节只是这批图主题，换品类应重选商品与色组。
- 白架蓝标清爽卖场：ASH007/012/022/038。天际线、落地窗、蓝色购物篮都是可选条件。
- 白架灰顶样品展厅：SH006/014/036。标签和品牌含义不能由配色推断。

AST007–014为空架参考；AST019为局部浅景深；ASH029带拼接边缘；ASH033/035/037/041–043为多画面。参见逐图评审，不能整图无条件继承。
